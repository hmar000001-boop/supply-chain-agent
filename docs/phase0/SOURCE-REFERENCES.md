## Version observations on 2026-11-16

- LangGraph4j 1.8.28 was released on 2026-11-13 and is the current 1.8 LTS release.
- LangGraph4j 1.9.9 is the current 1.9 release, but the maintainers describe 1.9.x as an evolving line with experimental features preparing for 2.0.
- LangChain4j stable core is 1.23.0; the Agentic module is on a separate beta line and is excluded from this project's runtime.

These are selection inputs, not proof of compatibility. The Maven build, tests and dependency tree must prove the combination used here.
