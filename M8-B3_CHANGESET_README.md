# M8-B3 mechanism ablation change-only patch

## Target baseline

Apply this patch on top of the **M8-B2 accepted repository** (M7 accepted/frozen, M8-B0 applied, both M8-B1 deliveries applied, M8-B2 matched-analysis patch applied). The user confirmed M8-B2 GitHub Actions CI green before starting M8-B3.

## Included

- Eight deterministic studies covering B1, B2, B3, B4, B6 and the selected interactions B2+B4, B1+B3+B6 and B4+B6.
- Production-mechanism evaluation probes and the `M8AblationCli` entry point inside `supply-chain-agent-evaluation`.
- Focused JUnit regression source covering the scenario/observation matrix, B2 consolidation, B3 coverage, B4 objective preservation, B6 interruption and the selected B1+B3+B6 composition.
- Versioned scenario/arm register, results clarification, condition-level summary CSV, paired contrast summary CSV and the exact JSONL output generated by the CLI.
- README, phase status, architecture traceability, decisions log and changelog updates.

## Experiment results recorded

- 8 studies;
- 19 scenario experimental units;
- 45 primary arm observations;
- 26 within-scenario paired contrasts;
- 18 deterministic replay rows, excluded from primary analysis;
- 63 raw observation rows total;
- 18/18 replay logical fingerprints matched.

All summary statistics and deltas are marked descriptive only. No population inference or statistical significance is claimed. The result report explicitly records unimplemented B1/B3 learning updates, B4 restart durability and B6 durable budget ownership as not evaluated. B5/GraSP remains closed.

## Apply

Extract the ZIP at the repository root, preserving paths. This is a change-only overlay, not a full repository. It contains no production mechanism, planner, action, authority, simulator, PostgreSQL migration or CI workflow changes.

## Reproduce after CI acceptance

```bash
./scripts/run-m8-ablations.sh
```

The script installs the evaluation reactor with tests skipped, then runs the deterministic CLI. The default output directory is `target/m8-b3-results`; set `M8_B3_OUTPUT_DIR` to change it.
