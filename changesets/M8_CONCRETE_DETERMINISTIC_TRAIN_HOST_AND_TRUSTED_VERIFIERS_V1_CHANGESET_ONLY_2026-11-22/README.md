## Apply

## What is provided

- A main-source `ScenarioFixtureDeterministicTrainPortsFactory` that creates fresh per-arm decision/lifecycle/authority ports, action registry and handlers, stateful stores, world/evaluator, workspace consumer, R2 repositories, audit counters and metrics.
- The `ComposedDeterministicTrainSessionFactory` compiles the actual full LangGraph4j application graph with a unique in-memory checkpoint saver/thread identity for each TRAIN arm.
- The deterministic profile disables live model execution and external connectors. All state-changing paths stop at the human approval boundary; any resumed approval is denied. No action dispatch occurs.
- A seven-role Ed25519 trust composition for endpoint, safety, hosted CI, B1 outcome, B2 approved procedure, B3 coalition outcome and B6 simulator-label evidence.
- Exact allow-listed public-key loading, symlink/extra-file rejection, and unique key-material enforcement. Public keys must be provisioned externally; private signing keys are not loaded or generated by this application.

## Mandatory evidence boundary

The concrete graph host emits **full-graph TRAIN telemetry only**. It does not issue downstream business-outcome evidence, approve/promote recovery procedures, create a verified B1/B3 outcome corpus, or manufacture B6 labels. The supplied R2 fixture verifiers explicitly reject test receipts/drafts as source outcomes. A complete training artifact bundle still requires independently sourced and independently signed B1/B2/B3 evidence and the separately verified B6 simulator labels. This changeset does not run any TRAIN batch.

No HOLDOUT or TRANSFER execution is enabled by this TRAIN host. B1/B3 remain SHADOW/DISABLED and B6 remains NOT_CALIBRATED.

## External trust provisioning

`M8TrustedResearchComposition.open(Configuration)` expects exactly seven `<issuer-id>.pub` Ed25519 SubjectPublicKeyInfo PEM files. It rejects missing/extra files, symlinks, private-key/certificate blocks, malformed keys, duplicate issuer IDs, and repeated public-key material. The seven private-key custodians must remain independent of this application and repository. Do not create dummy keys or sign synthetic outcomes to make the gate pass.

The canonical attestation file contract and issuer mapping are documented in `docs/phase8/M8-DETERMINISTIC-TRAIN-HOST-AND-TRUSTED-VERIFIERS.md`.
